# GTNH: Beyond the Stars 0.25.2

A fix release on top of 0.25.1, for **GTNH 2.9.0-RC-2**. It is safe to drop in over 0.25.1: no structure changes,
no new blocks or items, and existing machines keep running. As always, **back up your world first**.
[INSTALL.md](INSTALL.md) has the full guide. Install it on the server and on every client.

## Fixes

- **The Small Coal Boiler can be crafted again.** With Beyond the Stars installed, the boiler had no working recipe.
  The cause is mod load order. GT's recipe (bronze plates, a wrench, bricks and Et Futurum's **Blast Furnace**) looks
  for the Blast Furnace under the ore name `craftingBlastFurnace`. GT fills that name while it loads, but only if
  Et Futurum loaded first. Installing Beyond the Stars changed FML's load order so that GT now loads first, which
  left the name empty. Beyond the Stars now registers the Blast Furnace under that name itself, before GT builds its
  recipes. Every other recipe that asks for `craftingBlastFurnace` (some Bartworks and NH Core Mod recipes) comes
  back with it. A pack where the name is already filled is left alone. The log says which case applied (search for
  `craftingBlastFurnace`).
